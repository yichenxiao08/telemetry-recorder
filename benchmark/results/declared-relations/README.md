# Synthetic declared-relations validation

`validation.json` summarizes local gates and source/binary hashes.
`acceptance-final.json` is generated by `scripts/relationscheck` through the real
serve binary, ordinary probe OTLP, both new plain targets, `runs list`, immutable
cohorts and real HTTP evidence anchors. Its database path is repository relative.

`acceptance.json` retains the initial one-target check; its flag table was an
analytic fixture expectation. `acceptance-one-target.json` adds the measured
cross-tabulation from stored flag/violation cohorts and the off private argument.
The final report also checks the separate object-return admission fixture. These
are development checks of authored data, not blind or held-out accuracy claims.

`lane01-legacy.json` is the unmodified lane02legacy check against frozen lane-01
using a database copy and an independently built main-13509b0 binary.
`regression.json` hashes serialized shop results and exact trace CLI bytes.
Shop comparisons explicitly exclude only creation/elapsed wall-clock metadata;
their other result bytes must match the frozen reports. No frozen file was edited.

`python-tests.txt` retains the sandbox failure. Native passing suites are retained
as the one-target and final logs. `lint-final.txt` records the final format/vet/lint
gate. The local full race stream remains in the ignored workspace cache; the
checked summary records test/package counts and failures. Hosted CI verifies the
published head independently. Synthetic data only; no restricted source/report
or reserved-seed generation is part of this work.
